## Goal

In the TUI longer tasks is not shown correctly. We need to add the possability to create longer task cards that allow scrolling. When moving up and down.

## Acceptance Criteria

- [x] TaskDetail popup scrolls section content with ↑/↓ and j/k when content overflows the popup height
- [x] TaskDetail shows `↑ N more` / `↓ N more` indicators (matching Column.tsx style) when content is scrolled
- [x] TaskEditor auto-scrolls so the focused section stays visible when navigating with Tab / ↑/↓ past the bottom
- [x] TaskEditor shows `↑ N more` / `↓ N more` indicators when section content is scrolled
- [x] Footer hint in TaskDetail mentions ↑/↓ scroll keys
- [x] Existing behavior preserved when content fits within the popup (no indicators, no extra rows)

## Notes

`TaskDetail.tsx`: switched from natural ink wrap of section blocks to a flat
line-based model (`wrapText` flattens each section's heading + wrapped
content into typed lines). The sections box is now bounded
(`height={sectionsHeight}`) and slices `allLines` by a `scrollOffset` state.
Indicator rows are reserved when `total > sectionsHeight`. ↑/↓, j/k step
one line; PgUp/PgDn jump a page; cursor resets when the task changes.

`TaskEditor.tsx`: the metadata header (Title, Status, Priority, Assignee,
Tags, Depends) stays fixed. Renderable sections now flow into a bounded
sections area whose visible window is computed by walking section heights
(`sectionHeight` = 1 marginTop + 1 heading + wrapped content lines) from
`sectionScrollIdx`. A `useEffect` adjusts `sectionScrollIdx` so the focused
section always falls inside the window — works with Tab and ↑/↓ both before
and during editing.
