## Goal

Multiple tags could not be entered in the TUI editor: the input's value was regenerated from parsed tokens on every keystroke, so separators (comma/space) were normalized away as soon as they were typed. Same bug affected depends_on. Reported via GitHub issue.

## Notes

## Progress

Fixed: new `tui/tokens.ts` grammar (splits on comma/semicolon/space, collapses separator runs, dedupes) + `TokenLineInput` wrapper that owns the raw text while editing. Unit tests in `tokens.test.ts`. Display/re-edit format normalized to `tag1, tag2, tag3`.
