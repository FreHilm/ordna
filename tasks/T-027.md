## Goal

When writing a goal, it should be possible to move the cursor to change the text anywhere in the text.

## Acceptance Criteria

- [x] TUI multiline section editor supports left/right cursor navigation
- [x] Up/down arrows move cursor between lines (column preserved where possible)
- [x] Home (Ctrl+A) / End (Ctrl+E) jump to line boundaries
- [x] Ctrl+Left / Ctrl+Right jump by word
- [x] Insert and delete operate at the cursor position, not only at end
- [x] Behaviour applies to all multiline sections (Goal, Notes, Progress, etc.)

## Notes

Web side (TaskModal `<textarea>`) already supports cursor navigation natively — change is scoped to the Ink TUI editor in `packages/cli/src/tui/TaskEditor.tsx`.

## Progress
