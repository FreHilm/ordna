## Goal

Write the user-facing and plugin-author documentation for the new plugin architecture, then exercise the whole loader path end-to-end so we know it actually works before shipping. **No release in scope** — version bump, changeset, tag, and publish all live in T-030. This task is the verification gate the user clears before authorising the release.

## Acceptance Criteria

### Documentation

- [x] Root `README.md` gains a "Backends" section under "Packages" explaining the `provider:` config key, with a short table linking to plugin packages once they exist

When `@frehilm/ordna-jira` (T-008) ships later, this task's "Backends" section in the root README should grow a row. That work is owned by the Jira plugin task, not this one.

- 2026-05-14: Verification round against `features/plugin-be`. (a) File-provider reads / queries against this repo's `tasks/` directory: `ordna list`, `ordna show T-008`, `ordna list -s done` all returned correct results. (b) Mock-provider end-to-end on `/tmp/ordna-mock-test/`: `ordna web` SIGINT'd in the background — initially **failed silently** (process exited 0 but `dispose()` never fired). Traced to a re-entrancy bug in T-023's web SIGINT/SIGTERM wiring: the CLI's own shutdown handler `await handle.close()` returned immediately because `runWeb`'s boolean `closed` guard short-circuited the second caller, so `process.exit(0)` killed the process mid-close. Fixed in `packages/web/src/server/start.ts` by storing the in-flight close promise (`closing: Promise<void> | null`) so all callers await the same chain, plus `removeAllListeners("upgrade")` + a 1500ms race-timeout on `server.close()` to defeat a `@hono/node-ws` upgrade-listener hang. Re-ran: both SIGINT and SIGTERM now produce `[ordna-mock] dispose() invoked` on stderr before the process exits cleanly. (c) TUI dispose check (manual): `ordna board` against the mock provider, pressed `q` — both `[ordna-mock] init() invoked` and `[ordna-mock] dispose() invoked` markers appeared, process exited cleanly. All 80 workspace tests still green after the fix.
